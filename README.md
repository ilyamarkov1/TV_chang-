# TV_chang- — CleanYourTV для Apollo Premium2K

Скрипты PowerShell для установки главного экрана [CleanYourTV](https://github.com/Gathin23/cleanyourtv) на Apollo Premium2K TV с Google TV. Проект сохраняет исходные настройки, собирает лаунчер из исходников и помогает переключить кнопку Home.

## Что потребуется

- Windows 10/11 x64, Git и Python 3.12 или 3.13 x64 с доступом из командной строки. Python можно установить с [python.org](https://www.python.org/downloads/windows/).
- Компьютер и телевизор в одной локальной сети, включённая отладка USB/ADB на ТВ.
- Интернет для загрузки Java, Android SDK и зависимостей первой сборки. Android Studio не требуется.
- Адрес телевизора из «Настройки → Сеть». Скрипт спросит его при подключении.

## Скачать

```powershell
git clone --recurse-submodules https://github.com/ilyamarkov1/TV_chang-.git
cd TV_chang-
```

Если репозиторий уже скачан без подмодуля:

```powershell
git submodule update --init --recursive
```

Исходники `cleanyourtv` подключены как подмодуль и закреплены на версии `f592b6d2db0cfa0e28779660f25ff65386a5ff9b`. Для воспроизводимости используйте эту версию; обновление до последней версии upstream не требуется.

## Запуск

Откройте папку `ApolloTV` в Проводнике и запустите нужный `.cmd` двойным щелчком. Права администратора не нужны.

| Файл | Действие |
| --- | --- |
| `INSTALL-TV.cmd` | Подготовить инструменты, сохранить исходное состояние, собрать и установить лаунчер |
| `FIX-HOME.cmd` | Переключить Home для уже установленного CleanYourTV и обновить нижний ряд без повторной сборки APK |
| `RESTORE-TV.cmd` | Вернуть прежний Home и восстановить обработчики, отключённые этим скриптом |
| `CHECK-TV.cmd` | Проверить подключение и текущий Home без изменения настроек ТВ |
| `PREPARE-PC.cmd` | Заранее скачать Java/SDK и часть зависимостей, без подключения к ТВ |
| `CHANGE-BACKGROUND.cmd` | Выбрать картинку для главного экрана или вернуть чёрный фон |

При первом запуске прочитайте условия Android SDK и подтвердите их, если согласны. На телевизоре подтвердите запрос «Разрешить отладку USB?». Если VPN мешает доступу к локальной сети, пользователь самостоятельно настраивает доступ или отключает VPN на время подключения.

Адрес и обычный сетевой порт ADB также можно передать явно:

```powershell
.\ApolloTV\INSTALL-TV.cmd -TvAddress <IP-телевизора> -Port 5555
```

Замените `<IP-телевизора>` фактическим адресом без угловых скобок. Для восстановления передавайте такие же параметры в `RESTORE-TV.cmd`.

Если ТВ предлагает только беспроводное сопряжение с кодом и TLS-портом, сначала выполните [сопряжение штатным ADB](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi), затем включите обычный сетевой ADB командой `adb -s <адрес:порт-подключения> tcpip 5555`. Если прошивка запрещает этот режим, остановитесь: Python-клиент upstream не поддерживает TLS-сопряжение самостоятельно.

## Если APK установился, но Home остался прежним

Запустите `FIX-HOME.cmd`. Если прошивка удерживает Home за Google TV Launcher, скрипт проверит владельца сохранённой Wi-Fi-сети и предложит отключить только:

1. `com.google.android.tungsten.setupwraith` — мастер первоначальной настройки Google TV;
2. `com.google.android.apps.tv.launcherx` — штатный главный экран Google TV.

Для продолжения введите `SWITCH`. Отключение выполняется штатным `tools/disable.ps1` из cleanyourtv с сохранением состояния и проверками Home, Wi-Fi, системных пакетов и обработчиков входов. Принудительные флаги не используются. CVTE-лаунчеры автоматически не отключаются.

Если сеть принадлежит мастеру первоначальной настройки, скрипт остановится до отключения пакетов. Переподключите сеть через настройки ТВ и повторите проверку. Нельзя отключать setupwraith, пока он владеет сохранённой сетью: это может удалить подключение и оборвать ADB.

После переключения нажмите настоящую кнопку Home на пульте и введите `YES`, если появился новый экран. Другой ответ запускает возврат исходного Home. При появлении экрана восстановления Google TV или чёрного экрана сначала выполните `RESTORE-TV.cmd`, сохраняя отладку включённой.

Отключение системных обработчиков может повлиять на Chromecast и отдельные кнопки пульта. Проверьте их, а также HDMI, Settings, голосовой поиск, видео и удержание громкости. При проблеме верните исходное состояние через `RESTORE-TV.cmd`.

## Нижний ряд

Семь мест для приложений в порядке:

**YouTube → VK Видео → Rutube → Twitch → Кинопоиск → Okko → Wink.**

Пакеты распознаются среди установленных приложений. Если подходящий пакет не найден или найдено несколько, скрипт предложит указать его либо нажать Enter и настроить плитку позднее. Исправить ряд можно пультом: удерживать OK на Settings → Edit dock.

Happ, Яндекс Браузер, v2raytun и остальные пользовательские приложения сохраняются. Системная телеметрия массово не отключается. Замена главного экрана не убирает рекламу внутри приложений, включая YouTube.

## Изменить фон главного экрана

1. Включите отладку и подключение ADB на телевизоре.
2. Запустите `ApolloTV/CHANGE-BACKGROUND.cmd` двойным щелчком.
3. Введите `1`, чтобы выбрать картинку с компьютера, или `2`, чтобы вернуть чёрный фон. Enter отменяет действие.
4. Дождитесь загрузки и проверьте главный экран, затем выключите отладку.

Поддерживаются JPG, PNG и BMP до 50 МБ. Рекомендуется горизонтальная картинка 16:9. Скрипт создаёт отдельную JPEG-копию размером не более 1920×1080 и добавляет затемнение 20% для читаемости текста. Оригинальная картинка сохраняется на компьютере. Для смены фона сборка APK и загрузка Java/SDK не требуются.

Из PowerShell можно сразу указать картинку и затемнение от 0 до 90%:

```powershell
.\ApolloTV\CHANGE-BACKGROUND.cmd -WallpaperPath "C:\Pictures\background.jpg" -WallpaperDim 30
.\ApolloTV\CHANGE-BACKGROUND.cmd -ResetWallpaper
```

Используется штатный механизм тем cleanyourtv. Имена приложений и остальные параметры текущего JSON сохраняются; настройки лаунчера, выбранные отдельно с пульта, могут вернуться к значениям темы. Набор вращающихся обоев заменяется выбранной картинкой. При последующем запуске установки/исправления Home выбранный через скрипт фон сохраняется.

## Резервные записи и завершение

Рабочие файлы находятся в `%USERPROFILE%\ApolloTV-Tools`:

- `backups` — первоначальный Home, списки пакетов, настройки и снимки;
- `logs` — журналы запусков;
- `cleanyourtv` — рабочая копия upstream;
- `android-sdk`, `gradle-cache`, `downloads` — инструменты и кэш.

Штатные инструменты cleanyourtv также хранят записи отката в `%USERPROFILE%\.cleanyourtv`. Сохраните обе папки. Это резервные записи изменяемых настроек, а не полный образ прошивки и не копия данных приложений. Первоначальная запись не перезаписывается при повторном запуске.

После успешной проверки перезагрузите ТВ и снова проверьте Home. Затем выключите USB/сетевую/беспроводную отладку, отзовите разрешения отладки и перезагрузите ТВ. Для будущего отката подключение ADB потребуется включить снова.

Не публикуйте резервные записи, ключи и полные журналы: в них могут быть сведения об устройстве и сети. Для локального сохранения адреса можно создать `ApolloTV/local-settings.json` — этот файл исключён из Git:

```json
{
  "TvAddress": "<IP-телевизора>"
}
```

## Проверки и ограничения

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ApolloTV\Test-ApolloTV.ps1
```

Проверки используют имитацию ТВ и не подключаются к реальному устройству. Они покрывают сохранение исходного состояния, отказ от отката на другом устройстве, проверки Wi-Fi, назначение Home, частичные ошибки и возврат системных обработчиков.

На одном Apollo Premium2K TV с Android 14 подтверждены установка APK и возврат исходного Home. Новый сценарий отключения двух обработчиков проверен на имитации, но ещё не подтверждён на реальном ТВ после перезагрузки. Совместимость с другими прошивками не гарантируется.

## Исходный проект

Лаунчер и защитные инструменты взяты из [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv). Их исходники и собственная лицензия находятся в подмодуле `cleanyourtv`. Этот репозиторий добавляет сценарии запуска для Windows; код и защитные проверки upstream не изменяются.
